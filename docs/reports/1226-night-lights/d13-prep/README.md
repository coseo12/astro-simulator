# #1226 D13 — 실 Chrome GUI 사용자 육안 확인 준비물

계약 D13 (§915 예외 불가 — 시각 효과) 의 **준비물**이다. **사용자 육안 확인 결과는 여기에 적지 않는다** — 사용자가 이슈 코멘트로 기록한다. 아래 캡처는 스크립트가 찍은 것이고 육안 확인을 대체하지 않는다 (#1215 선례 — qa 「실 Chrome」 이 사람 육안 `0` 이었다).

## 준비 (한 번)

```text
pnpm --filter @astro-simulator/core build
pnpm --filter @astro-simulator/web dev
```

브라우저는 **실 Chrome** 이어야 한다 (Playwright 번들 chromium 아님). 화면 우상단 HUD 의 `renderer · webgpu` 표시로 WebGPU 백엔드를 확인한다. 확인 중 **DevTools 콘솔을 열어 에러 0** 을 본다.

## 확인 항목 4종

| #   | 무엇을 보는가                                                                              | URL                                                    | 보는 법                                                                                                                                                                                        |
| --- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **밤면 정면** — 불빛이 밤쪽 육지에만, 도시처럼 몰려서 보이는가                             | `http://localhost:3000/?focus=earth&t=2451808&speed=0` | 지구를 드래그해 태양 반대쪽 (어두운 면) 이 정면에 오게 돌린다. 정확히 반태양점에 서면 태양 glow 가 화면을 덮으므로 30~45° 정도 비껴 본다                                                       |
| 2   | **terminator** — 낮/밤 경계에서 불빛이 갑자기 켜지지 않고 황혼 폭 안에서 서서히 들어오는가 | 같은 URL                                               | 경계선 근처를 확대해 본다 (`W 0.12` — `ndl ≥ 0` 에서는 정확히 0)                                                                                                                               |
| 3   | **구름이 불빛을 덮는가**                                                                   | `…&clouds=off` 를 붙인 탭과 나란히 비교                | 같은 시점에서 구름 ON 탭의 불빛이 구름 아래로 가려지는지 본다                                                                                                                                  |
| 4   | **LOD 경계 줌 깜빡임**                                                                     | `http://localhost:3000/?focus=earth` (기본, 자전 ON)   | 지구에서 천천히 줌아웃 → 줌인 하며 불빛이 깜빡이거나 분포가 튀는지 본다. 특히 (a) 마스크 경계 (투영 반경 16 px 부근 — 지구가 아주 작아지는 구간) (b) high → mid → low 전환 (c) 자전 중 shimmer |

비교 대조군은 `…&nightlights=off` 다 (불빛만 꺼진 같은 프레임).

## 스크립트 캡처 (참고용 — 판정 아님)

**이 폴더에는 캡처를 두지 않는다.** 가장 가까운 기존 캡처는 D1 승인 라운드의 g1 3장이다 — [`../d1-candidates/`](../d1-candidates/) 의 `g1-night.png` · `g1-terminator.png` · `g1-night-clouds-off.png` (실 Chrome GUI · `channel: chrome` · `headless: false` · WebGPU · 콘솔 에러 `0` · JD `2451808.0` · `rotate=off` · pause · 카메라 `fov × 0.4` 확대. 메타는 같은 폴더 `capture-meta.json`).

⚠️ 그 3장은 **`packages/core` = `c4e0ee9` (D1 3차 후보) 빌드**로 찍었다 — D1 승인값 접기 (`ff203b0`) 와 #1228 mid LOD 마스크 fix 이전이다. 파라미터는 g1 그대로지만 **현 브랜치 tip 의 픽셀과 같다는 보증은 없다**. 위 확인 항목 4 (LOD 경계) 는 #1228 이 바꾼 축이므로 그 캡처로 대체할 수 없다.

캡처 스크립트는 임시였고 커밋 전에 삭제했다 (volt #67) — 위 URL 과 레시피로 재현한다.
