### (c) 측정 상세 — 두 번째 추론 축도 실패한다

(b) 가 _"낱말 그물"_ 계열이라면 (c) 는 _"행위 흔적"_ 계열이다. 등재 대상인 횡단 거버넌스 ADR 은
대개 가드·에이전트·워크플로 변경을 동반하므로, ADR 을 **추가한 커밋**이 거버넌스 표면을 같이
건드렸는지로 추론할 수 있다는 가설.

```bash
# 각 ADR 의 최초 추가 커밋을 찾아 그 커밋의 변경 경로를 본다
c=$(git log --diff-filter=A --format=%H -- "$f" | tail -1)
git show --pretty=format: --name-only "$c" | grep -E '^(CLAUDE\.md|\.claude/|scripts/|\.github/)'
```

실측 (rev `fda9475`, 로컬 ADR 98건): **TP 5 / FP 25 / FN 3 / TN 65** → precision **16.7%**,
recall **62.5%**. 미포착 3건은 `907`·`971`·`1014`.

### (b)(c) 결합 — cross-validate 지적으로 추가 실측

초판은 두 축을 **단독으로만** 측정하고 _"독립 축 2개가 같은 벽에 막힌다"_ 로 결론했다. agy 가
**결합 미측정**을 정확히 지적했고 (Q3-①), 실측 결과 **초판 서술이 부정확했다** — 두 축의 미포착
집합이 다르므로(`(b)`: `971`·`1010`·`1014` / `(c)`: `907`·`971`·`1014`) OR 결합은 recall 을
올린다. 4점 전량 재측정 (같은 rev, 후보 집합 = 로컬 ADR 98건, recall 분모 = 로컬 등재 8):

| 조합 | 후보 | TP | precision | recall |
|---|---|---|---|---|
| (b) 참조 단독 | 19 | 5 | **26.3%** | 62.5% |
| (c) co-change 단독 | 30 | 5 | **16.7%** | 62.5% |
| **(b) AND (c)** | 11 | 4 | **36.4%** | **50.0%** |
| **(b) OR (c)** | 38 | 6 | **15.8%** | **75.0%** |

agy 의 예측(_"AND 결합 시 precision 35~50% 상승 가능"_)은 **36.4% 로 적중**했다. 그러나 결론은
바뀌지 않는다 — **precision 최대치(AND 36.4%)는 recall 50% 를 대가로 얻고, recall 최대치
(OR 75%)는 precision 15.8% 로 떨어진다.** 네 점 중 어느 것도 1.0 근처가 아니며 트레이드오프
곡선 위를 이동할 뿐이다. 정정된 결론: _"같은 벽"_ 이 아니라 **_"결합해도 곡선이 1.0 모서리에
닿지 않는다"_** 이고, 그 뒤에 남는 것은 추론이 아니라 **선언**이다.

## 결정

### 1. 자기 선언 마커 규약을 **기각**한다 — (d)(f) 폐기, (e) 는 재도입 트리거로 보류

근거 4개. 전부 측정값이거나 본 저장소의 기존 구조에서 도출된다.

**1-1. 선언 계열의 precision 1.0 은 _등재 기준_ 에 대한 것이 아니다.**
마커가 보장하는 것은 **"마커 값 ↔ 인덱스 표 행"** 의 일치이지 **"마커 값이 계약 (1) 에 비추어 옳은가"**
가 아니다. 후자는 여전히 사람(또는 에이전트)의 의미론적 판정이며, **#1015 에서 실패한 판정이 정확히
그 판정이다.** 마커는 판정 누락을 판정 오기로 **이동**시킬 뿐 제거하지 않는다. 표의 별표 `*` 는
이 뜻이다 — 분모가 바뀐 precision 1.0 이다.

**1-2. 저마찰 답이 표적 클래스에서만 틀린다 (base rate 8.2%).**
로컬 ADR 98건 중 등재는 8건 — **91.8% 가 `비대상`** 이다. 필수 필드의 저마찰 답(`비대상`)은
README 편집을 **요구하지 않고**, 고마찰 답(`등재`)은 요구한다. 즉 마커는 **자신이 원하는 행동의
반대 방향으로 비용 기울기를 만든다.** 반사적으로 채운 값은 91.8% 확률로 맞고, 틀리는 8.2% 가
**가드가 존재하는 이유인 바로 그 클래스**다. CLAUDE.md §가드 설계 원칙(measurement-first)에 비추어,
발화하지 않는 가드보다 **틀린 방향으로 발화를 유도하는 가드**가 나쁘다.

⚠️ **1줄 근거 의무화로 이 축을 막을 수 있는가 (cross-validate Q1-①).** 막지 못한다는 데 agy 와
합의했다 — `비대상 — 횡단 규약 없음` 류의 **상투 문구 복사**가 즉시 자리를 메운다 (compliance
illusion). 근거 의무화는 우회 비용을 조금 올릴 뿐 기울기의 **방향**을 바꾸지 못한다. 그럼에도
재도입 시에는 넣는다 — 기울기를 없애지는 못해도 완화는 하기 때문이다 (§재도입 트리거).

**1-3. 본 저장소의 선행 선언 기제는 삼각측량으로 신뢰를 얻는데, 등재 여부에는 대조할 신호가 없다.**
`(upstream-only)` 표기도 자기 선언이다. 그런데 그것이 가드로 성립하는 이유는 선언 자체가 아니라
**3원 일치** — `로컬 파일 부재 ⟺ 주제 셀 표기 ⟺ allowlist 등록` — 즉 **선언 1개 + 독립 물리 신호
2개**를 대조하기 때문이다 ([`20260812-1005`](20260812-1005-adr-index-status-guard.md) §결정 3).
등재 여부에는 대조할 독립 물리 신호가 **없다** — 있었다면 그게 (b)(c) 였고 최대 36.4% 로 측정
실패했다. 삼각측량 없는 단독 선언을 대조하는 가드는 **사람이 쓴 두 문자열이 같은지**를 확인하고
PASS 를 출력한다.

⚠️ **원칙이 아니라 트레이드오프로 읽어야 한다 (cross-validate Q2 이견 수용).** 초판은 이를
_"단독 선언은 가드의 정본이 될 수 없다"_ 는 **원칙 단언**으로 썼고, agy 가 과도한 순수주의라고
지적했다 — `CODEOWNERS`·라이선스 헤더·마이그레이션 태그는 전부 삼각측량 없는 단독 선언이지만
유용하다. **지적을 수용해 트레이드오프 서술로 내린다.** 다만 반례들과의 **차이는 유지한다**:
`CODEOWNERS` 의 선언은 **그 자체가 집행**이다 (PR 리뷰어가 실제로 지정된다 — 선언이 곧 행동이라
틀린 선언은 잘못된 리뷰어라는 **관측 가능한 결과**를 낳는다). 등재 마커의 선언은 **부기**다 —
틀려도 아무 일이 일어나지 않고, 유일한 관측 가능 결과가 _"README 표와 같은가"_ 뿐이다.
정정된 근거: 원칙상 불가가 아니라, **본 저장소에서 이 마커가 주는 인식적 환기 이득 <
1-2 의 기울기 역전 위험**이다. 환기 이득은 §결정 5 가 **훨씬 싼 값에** 회수한다.

**1-4. retrofit 을 생략하면 가드가 무력화되고, 하면 비용이 실측된다.**
마커 부재를 통과시키면 **98건 중 90건이 마커 없이 전건 통과**해 _"마커 부재 = 미등재 대상"_ 인지
_"아직 개정 안 된 파일"_ 인지 구분 불가다 (가드 전건 통과 = 무력화). 따라서 (d) 는 98 파일 retrofit 이
**선택이 아니라 전제**다. (f) 는 그 목록을 파일 밖으로 옮겼을 뿐 90 항목의 순수 부기를 영구 유지해야
하고, 이는 volt [#120](https://github.com/coseo12/volt/issues/120)(_"중복 출처 제거 > 매칭 가드"_)의
반대 방향이다 — 인덱스 표라는 정본이 이미 있는데 그 여집합을 사본으로 관리한다.

(e)(cutoff 상수 + 등재 8건만 retrofit)는 1-4 를 8 파일로 낮추지만 **1-1 ~ 1-3 을 그대로 상속**한다.
비용 축만 개선되고 결함 축은 동일하므로 지금 채택할 근거가 없다 — 다만 재발이 누적되면 비용/편익이
역전되므로 §재도입 트리거에 **설계를 완성된 형태로 박제**한다.

### 2. 잔여 3항(이슈 #1020 의 2·3·4항)은 **전건 채택**한다

세 항목 모두 `scripts/verify-adr-index.mjs` 의 단언 수·구조를 건드리므로 한 PR 에서 처리하고,
**단언 수 갱신은 마지막에 일괄 1회**로 한다 (아래 §결정 3).

**2-1. `main()` 경로 커버리지 — `child_process` import 0 을 깨지 않고 달성 가능 (실측).**
이슈가 우려한 트레이드오프(`process.exit` 우회 리팩토링 또는 `child_process` spawn)는 **발생하지
않는다.** 현행 `main()` 은 이미 `process.exit` 를 호출하지 않고 **종료 코드를 return** 한다
(`:347`/`:352`/`:359`/`:384`/`:387`). 전역 의존은 `process.argv`(`:341`)와
`process.env.ADR_INDEX_ROOT`(`:349`) 둘뿐이라 **인자 기본값 주입**만으로 순수 호출이 된다.

```js
function main(args = process.argv.slice(2), env = process.env) { … }
function isSelfTestMode(args) { return args.length === 1 && args[0] === '--self-test'; }
function dispatch(args) { return isSelfTestMode(args) ? selfTest() : main(args); }
process.exit(dispatch(process.argv.slice(2)));
```

`isSelfTestMode` 를 순수 술어로 분리하는 것이 요점이다 — self-test 가 `dispatch(['--self-test'])` 를
실행하면 **무한 재귀**이므로, 실행이 아니라 **술어를 단언**한다. 실행 불가능한 마지막 한 줄
(`process.exit(dispatch(…))`)은 `F15` 가 이미 쓰고 있는 **정적 자기 참조 단언**으로 덮는다
(자기 소스를 읽어 배선 문자열 존재를 단언 — 골든 벡터 패턴).

실측 (프로토타입, rev `fda9475` 기준 throwaway 후 삭제):

### 4. 본 ADR 자신은 인덱스 **비대상**이다

- **§재검토 조건 1 (Q1-②)** — 임계 2 가 자의적이지 않다는 데 합의. 근거 서술을 본문에 추가.
- **recall 분모 8 (Q3-②)** — _"upstream-only 3건은 순회 대상에 물리적으로 들어올 수 없으므로
  분모 8 은 구조적으로 정확"_.

**이견 수용**
- **Q2 — §결정 1-3 의 원칙 단언을 트레이드오프 서술로 하향.** 원안: _"삼각측량 없는 단독 선언은
  가드의 정본이 될 수 없다"_ (원칙). 수정: _"본 저장소에서 이 마커의 환기 이득 < 1-2 기울기 역전
  위험"_ (트레이드오프). 수용 근거: `CODEOWNERS` 반례가 정확하다 — 단독 선언형 가드는 실무에서
  널리 작동한다. **단, 반례와의 차이는 유지**했다 (`CODEOWNERS` 선언 = 집행 / 등재 마커 선언 =
  부기). 원칙을 통째로 철회하면 이번엔 반대 방향으로 틀린다.
- **Q3-① — 결합 휴리스틱 미측정.** 원안은 (b)(c) 단독만 재고 _"같은 벽"_ 이라 결론했다. 지적을
  받아 **AND/OR 를 실측**했고 초판 서술이 **부정확**함이 드러났다 (미포착 집합이 달라 OR 은
  recall 75% 로 상승). agy 의 _"AND precision 35~50%"_ 예측도 **36.4% 로 적중**. 4점 표를
  §후보 비교에 추가하고 결론 문장을 _"결합해도 곡선이 1.0 모서리에 닿지 않는다"_ 로 정정했다.
  **맹목 수용이 아니라 실측 후 수용**이다 — 예측이 맞았어도 결론(기각)은 바뀌지 않았다.
- **Q3-② — 소표본 표기.** 백분율을 통계적 추정으로 읽히지 않게 §재검토 조건 2 에 명시 정정.

**Claude 재분석으로 기각한 외부 모델 제안**
- **Q4-① _"`CHANGELOG.md` 의 옛 표기(`F1~F15`)가 CI 의 단언 수 검사에 걸려 false alarm 을
  유발하는지 확인 필요"_ → 기각 (전제 미성립).** 실측: `.github/workflows/*.yml` · `package.json`
  전수에서 픽스처 라벨·단언 수를 검사하는 **자동 가드는 0건**이다 (`project-guards.yml:78`·`:139`
  는 주석). sweep 은 §결정 3 이 규정한 **수동 절차**이므로 CI false alarm 경로 자체가 없다.
  다만 수동 sweep 의 grep 결과에는 잡히므로, 그 지점은 §결정 3 의 **편집 금지 표**가 이미 덮는다.
- **Q2-② _"가드가 선언의 참을 검증 못 해도 Presence Check 로 충분하다"_ → 부분 기각.**
  Presence Check 의 가치 자체는 수용했으나(§결정 5 로 회수), 그 가치를 얻으려고 **커밋된 산출물
  98 파일 + 영구 필드**를 지불할 이유는 되지 못한다. 환기는 작성 시점 텍스트에서 나오지 커밋된
  필드에서 나오지 않는다 — 같은 이득을 §결정 5 가 1줄에 회수한다.

**고유 발견 (본 PR 반영)**
- **Q4-② 사전(작성 시점) 축 누락** → **§결정 5 신설**. 후속 이슈로 분리하지 않고 본 PR 범위에
  넣었다. 판단: 이슈 #1020 의 **비목표는 산문 역참조 검출 / upstream fetch CI 2건**뿐이라
  상충하지 않고, _"마커를 기각하면 #1015 클래스는 무엇이 다루는가"_ 라는 질문이 기각 판정의
  **논리적 짝**이라 분리하면 맥락이 유실된다. 다만 개입은 **1줄**로 제한해 스코프 팽창을 막았다.

**Claude 편향 셀프 체크** — 호출 전 4축 중 **2축(폐기 프레이밍 / 순수주의) 미통과** 판정해 Q1·Q2
명시 질문으로 삽입했고, **그중 순수주의 축에서 실제로 이견이 수용됐다** (§결정 1-3 하향). 셀프 체크가
자기 진단에 성공한 사례다. 반면 **초판의 실질 결함(결합 미측정)은 셀프 체크 4축 어디에도 걸리지
않았고 외부 모델이 잡았다** — 4축은 *프레이밍* 편향 목록이지 *측정 설계* 누락을 잡지 못한다.
낙관적 일정 축은 프로토타입 실측(36 단언 PASS)으로 대체했으나 **프로토타입 ≠ 프로덕션**이다
(sweep · CHANGELOG · Amendment · 스킬 개정은 프로토타입에 없다). 결합 축은 §결정 2·3 이 세 항목을
같은 파일·같은 단언 수를 건드리는 **결합 변경**으로 인지해 1 PR 직렬 + 최종 1회 sweep 으로 배치했다.
