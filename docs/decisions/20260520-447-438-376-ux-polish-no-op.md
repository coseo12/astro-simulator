## §2 NO-OP 결정 근거

### #447 (G8a 무응답 시각 큐) — NO-OP

- 본 세션 (2026-05-19~20) 의 6 PR 사용자 D-T2 검증 모두 "tier 전환 중 무응답" 보고 0건
- #444 PR #516 (`__simCore.metrics.tierTransitionInputDrops`) 머지로 G8a 입력 drop 카운트 측정 인프라 도입 — 일정 운영 후 분포 관찰 → 격상 결정 데이터
- 시각 큐 (vignette / fade / cursor / spinner) 구현은 시각 효과 + 단위 테스트 + browser-verify 부담. 사용자 보고 0건 시점에 ROI < 보류 ROI

### #438 (수성 직경 vs 궤도 비율) — NO-OP

- 발화 1건 (PR #437 D-T2, 2026-05-10) 후 동일 보고 0건
- 현재 운영 sunScale = 50 (Amendment 2026-05-01) + R3 venus 추가로 시각 비율 자연화 완료
- 옵션 A (수성 scale 700→1500 추가 상향) 은 fact-first 트레이드오프 (volt #74). 추가 보고 발생 시 별도 forensic ADR

### #376 (시각 비율 변경 소통) — NO-OP

- 시각 비율 변경 (옵션 (c) Amendment 2026-05-01) 후 CHANGELOG `### Behavior Changes` 박제로 사용자 가시성 1차 확보
- 앱 내 onboarding 토스트 / banner 는 i18n + dismiss 로직 + 자동 dismiss 타이밍 + 회귀 가드 부담. 사용자 만족도 polishing 단독 ROI 낮음
- volt #74 (UX-DoD) 패턴은 본 정책 영역의 별도 DoD 축으로 박제 — `### Behavior Changes` 가 SSoT 로 작동

## §3 재검토 트리거 (보류 해제 조건)

### #447 재검토 트리거

1. 사용자 D-T2 또는 외부 보고에서 "tier 전환 중 무응답" 오인 발생
2. #444 (`tierTransitionInputDrops`) 데이터에서 분당 평균 ≥ 5회 입력 시도 관찰 (G8b 격상 결정과 동반)
3. 모바일 사용자 비율 증가 + G8a 윈도우 500ms 가 모바일 터치에서 더 자주 충돌 보고

### #438 재검토 트리거

1. 동일 보고 ("본체를 감싸는 작은 원") 추가 발생 (n ≥ 2)
2. R4 (earth) 진입 시 동일 패턴 (지구 본체 vs 1 AU 궤도) 재현
3. BODY_SCALE 정책 변경 ADR — fact-first 회복 또는 새 정책

### #376 재검토 트리거

1. 시각 비율 변경 사용자 소통 누락으로 "왜 이렇게 보이지?" 사용자 보고
2. R4+ 진입 시 시각 변화 큰 변경 (옵션 (e) log scaling 등) 채택
3. UX-DoD 정책 강화 ADR — 시각 변경 알림 트리거 표준 박제
