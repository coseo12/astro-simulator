## 시나리오별 상세 (3회 raw + median)

### Scenario 1 — idle (정지 상태 FPS)

| Run        | v0.12.0   | feature   |
| ---------- | --------- | --------- |
| 1          | 17.48     | 89.53     |
| 2          | 21.23     | 98.97     |
| 3          | 22.09     | 99.93     |
| **median** | **21.23** | **98.97** |

**분석**: LOD low billboard 전환으로 sub-pixel body(소행성 / 외행성) 의 draw call 대폭 감소. idle 시나리오는 T1 solar 뷰 기본값 — 100+ body 가 sub-pixel 로 모이는 지점이라 가장 큰 개선폭 관찰.

### Scenario 2 — play-1d (1-day time preset 재생 상태)

| Run        | v0.12.0   | feature   |
| ---------- | --------- | --------- |
| 1          | 18.16     | 77.87     |
| 2          | 18.04     | 86.10     |
| 3          | 18.40     | 80.29     |
| **median** | **18.16** | **80.29** |

**분석**: time advance + 매 프레임 궤도 업데이트 시 물리 계산이 주된 CPU 부하. LOD 는 렌더 경로 최적화라 play 모드에서도 렌더 병목 해소 효과 발현. idle 대비 약간 낮은 개선폭 (342% vs 366%) 은 물리 계산이 LOD 혜택을 받지 않기 때문.

### Scenario 3 — play-1y (1-year time preset 재생 상태)

| Run        | v0.12.0   | feature   |
| ---------- | --------- | --------- |
| 1          | 19.73     | 77.71     |
| 2          | 17.38     | 86.96     |
| 3          | 18.48     | 83.92     |
| **median** | **18.48** | **83.92** |

**분석**: play-1d 와 유사 패턴. 1y time scale 에서도 LOD billboard 전환이 주 개선원.

### Scenario 4 — focus-earth (지구 focus, body tier)

| Run        | v0.12.0   | feature   |
| ---------- | --------- | --------- |
| 1          | 69.25     | 66.40     |
| 2          | 73.36     | 72.73     |
| 3          | 77.21     | 74.37     |
| **median** | **73.36** | **72.73** |

**분석**: focus 시에는 지구가 화면 40% 차지 → T3 body tier 전환 → LOD high 유지. 배경 body 는 거리 임계로 low 전환되나 T3 에서는 이미 배경 body 가 far clip 근처라 GPU 입장에선 culling 효과 근사. LOD hook 순회 오버헤드 (O(N)) 만 측정되어 -0.86% 미미한 회귀. **임계 5% 대비 여유 58배**.

### Scenario 5 — focus-neptune (해왕성 focus, body tier)

| Run        | v0.12.0   | feature   |
| ---------- | --------- | --------- |
| 1          | 89.05     | 80.51     |
| 2          | 91.16     | 87.58     |
| 3          | 92.26     | 88.62     |
| **median** | **91.16** | **87.58** |

**분석**: 해왕성 focus 시 T3 body tier. LOD hook 오버헤드가 focus-earth 보다 소폭 크게 나타남 (-3.93% vs -0.86%). 해왕성은 `planet-giant` (body.mass 1.02e26 kg) 분류로 `radius-multiple 10R` 임계 적용 — 전환 경계에 걸릴 가능성. 이후 Phase (P11-C) 에서 GPU tier 기반 throttle (10 프레임 당 1회 재계산) 도입 시 해소 여지 있음. **현재는 임계 5% 이내로 허용**.

## 측정 유의점

1. **측정 도구**: `scripts/bench-scene.mjs`. 5 scenario × 3 sec × 3회. fps 는 `requestAnimationFrame` 기반 count/duration.
2. **샘플링 노이즈**: idle run 1 (17.48) 이 runs 2,3 대비 낮음 — 워밍업 영향. median 방식으로 자연 흡수.
3. **LOD 상태**: 두 측정 모두 기본 `?lod=auto` (URL override 미지정, scene 자동 판정). B.1 변경은 주로 idle/play 시나리오에 집중된 개선.
4. **focus-earth / focus-neptune 이 feature 에서 fps 감소**: LOD hook 의 O(N) 순회 오버헤드. P11-C (WebGPU/GPU tier 기반 프레임 간 throttle) 에서 더 개선 여지. 현재 임계 5% 이내 허용.
