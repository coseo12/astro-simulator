# 디자인 품질 루브릭 (UI 프로젝트)

> CLAUDE.md `## 디자인 품질 루브릭 (UI 프로젝트)` 가지치기 위임 (이슈 #266 / PR #290). CLAUDE.md 본문은 1줄 포인터만 유지.

UI 가 포함된 작업에서 4축으로 품질을 평가한다:

| 기준 | 가중치 | 설명 |
|------|-------|------|
| Design Quality | 30% | 색상, 타이포그래피, 레이아웃이 일관된 전체로 느껴지는가 |
| Originality | 30% | 템플릿/라이브러리 기본값/AI 생성 패턴(보라색 그라데이션 등)을 탈피했는가 |
| Craft | 20% | 타이포그래피 계층, 간격 일관성, 색상 조화, 대비 비율 |
| Functionality | 20% | 미학과 무관한 사용성 (내비게이션, 폼, 인터랙션) |

## 적용 절차

1. UI 작업 종료 직전 4축 점수 자체 평가 + 사용자 검토
2. 점수 < 70% (가중 합산) 인 축은 **개선 작업 의무**
3. PR 본문에 4축 점수 박제 (선택 — 마일스톤 PR 권고)
4. 디자인 품질이 의사결정 분기점이 된 경우 ADR 권고 — 트리거 조건: **컴포넌트 라이브러리 / 디자인 시스템 선택 시** (CLAUDE.md `### 아키텍처 결정 기록 (ADR)` 트리거 정합)
